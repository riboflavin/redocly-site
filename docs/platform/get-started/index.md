# Get started with Redocly

{% configOptionRequirements plans=$frontmatter.plans /%}

Redocly projects are managed and deployed on the Redocly platform, the cloud platform.
For development, you can use the built-in the Redocly editor, or work locally using your favorite editor.

Start your first project either in your browser with Redocly, or using your local development tools:

- [Start with the web editor](start-reunite-editor.md): Use the built-in editor in Redocly.
- [Start with local development](start-local-dev.md): Use a code editor on your local device.

## Next steps

After you set up your project, try these common configuration tasks:

- [Add an OpenAPI description](../content/api-docs/add-openapi-docs.md)
- [Configure the sidebar](../navigation/sidebars.md)

Redocly products receive regular updates.
If you're working locally, or have defined a version of Redocly products in your project, consider [updating to the latest version](./upgrade-realm-version.md).
